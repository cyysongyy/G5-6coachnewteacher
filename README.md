# Teacher Coach 教師教練（單機版 v1.0）

> Don't just solve the problem. Train the teacher.
> 不只是解決問題，而是訓練自己成為更好的老師。

一個自帶邏輯的單一網站。沒有任何後端、沒有帳號登入、沒有外部套件、不蒐集個資，
所有事件記錄都只儲存在**這支手機（瀏覽器）的本機空間（localStorage）**裡。
GitHub／GitHub Pages 在這裡只負責提供程式碼與網頁本身，不會經手、也不會儲存任何一筆教師輸入的資料。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 整個 App（HTML／CSS／JS 皆內嵌於單一檔案，離線可用） |
| `manifest.json` | PWA 設定，讓手機可以「加到主畫面」當作 App 使用 |
| `sw.js` | Service Worker，快取靜態檔案以支援離線開啟 |
| `icon.svg` | App 圖示 |

## 部署到 GitHub Pages

1. 進入這個 repo → **Settings ▸ Pages**。
2. Source 選 `Deploy from a branch` → Branch 選這個分支（或合併後的 `main`）／`(root)` → Save。
3. 約 1 分鐘後即可透過 GitHub Pages 網址開啟。
4. 用手機瀏覽器打開網址後，選「加入主畫面」，就會有一個獨立的 App 圖示，之後可離線使用。

## 資料與隱私

- 所有事件、診斷、行動方案、心理素質紀錄、反思與實驗結果，**只存在使用者當下裝置的瀏覽器 localStorage**。
- 沒有伺服器、沒有雲端同步、沒有第三方分析工具，App 本身不會把任何資料送出裝置。
- 換手機、清除瀏覽器資料、或改用無痕模式，記錄都不會被保留 —— 請在「設定」頁使用**匯出備份（JSON）**定期備份，之後可用**匯入備份**還原到新裝置。
- 遇到安全疑慮或高風險事件（肢體傷害、霸凌、自傷、不當對待、正式投訴、法定通報事件），App 會直接標示「請依學校正式程序處理」，並且**不會**產出行動建議 —— 這類事件永遠優先交給正式程序與專業協助，App 只做基本記錄與反思。

## 功能總覽（V1.0）

1. **今天 Home**：插畫風格首頁——今日挑戰橫幅、一鍵新增事件、**快速問答**（直接打字問任何問題，AI 立即回答，不用跑完整事件流程，需先在設定頁設定 AI）、四個彩色快速入口卡片（學生／班級／教學／成人關係）、今日 Mental Strength 圓環分數＋本週平均分數＋連續紀錄天數、輪播小提示、待回報的教師實驗提醒。
2. **事件輸入**：自然語言描述 + 結構化欄位（時間、場所、涉及人物、可觀察行為、目前處置）。
3. **問題診斷**：Primary／Secondary 類別（學生衝突、班級經營、教學、行政、人事）＋ 問題層次（L1 個人行為 → L4 學校制度）。
4. **風險檢核**：六項高風險指標，一旦命中即轉為「正式程序」提示，不進入教練與方案流程。
5. **教練提問（Coach Mode）**：依類別提供 3–4 個引導反思問題，並帶出對應的教育理論卡片（原則＋課堂應用），可選用自己的 AI API Key 取得更客製化的教練回饋。
6. **行動方案**：固定產出 NOW／TOMORROW／LONG TERM 三層模板，可編輯，也可選用 AI 一鍵生成客製化版本。
7. **Mental Strength Engine**：五大能力 — 自我覺察、情緒調節（含 PAUSE 提示）、認知彈性（事實 vs 解讀）、復原力、主動性（我能控制什麼）。
8. **反思與教師實驗**：每次事件收尾產生一句反思 ＋ 一個「明天只實驗一件事」的行動研究紀錄，隔天在首頁回報結果。
9. **事件記錄**：依日期分組的完整歷史清單，可查看詳情、編輯、刪除。
10. **教師成長儀表板**：問題類型分佈長條圖、Mental Strength 五角圖、依週的成長曲線。
11. **設定**：文字大小（小／標準／大／特大）、AI API Key 設定、隱私說明、JSON 備份／還原、清除所有資料。

## 教育理論資料庫

內建 32 條理論條目，涵蓋五大情境：學生衝突（SEL、修復式實踐、NVC…）、班級經營（Kounin、PBIS、回應式教室…）、課程教學（建構主義、UDL、形成性評量…）、學校行政（分散式領導、利害關係人管理…）、人事應對（情緒智能、非暴力溝通、困難對話…）。每一條包含理論名稱、核心原則、課堂應用。

## AI 教練（選用，預設關閉）

「設定」頁新增了「AI 教練」區塊，可以自行選擇並填入以下任一服務的 **API Key**：

- OpenAI
- Google Gemini
- Anthropic Claude

**預設不使用任何 AI，App 本身不會發出任何網路請求。** 只有在你主動：

1. 到「設定」頁選擇一個服務並填入自己的 API Key，且
2. 在「教練提問」畫面按下「詢問 AI 教練」、在「行動方案」畫面按下「用 AI 生成客製化建議」，或在首頁「有問題想問？」卡片直接送出一個問題，

那一次操作才會把當下的內容（事件細節，或首頁問答卡片裡你打的問題與最近幾則問答）直接從你的裝置送到你選擇的服務商，換取更客製化的教練建議、行動方案或直接的答案。這個請求**不會經過我們或任何中介伺服器**，但既然是直接呼叫，你的 API Key 也會出現在該次瀏覽器網路請求裡（這是所有「純前端＋自帶金鑰」工具的共同限制）。API Key 本身仍然只存在這支手機的瀏覽器 localStorage 裡，不會被 App 上傳或分享。

「教練提問」與「行動方案」用的是引導式、蘇格拉底式的教練人格（會先反問問題、幫你釐清而不是直接給答案）；首頁的「有問題想問？」則是刻意設計成**直接、簡化**的模式，同樣的 AI 服務與金鑰，但會直接、具體地回答問題，只顯示最近一則問答，適合想要快速得到做法、不想跑完整流程的時候使用。

不使用這個功能完全不影響其他功能——事件記錄、診斷、規則式教練提問、內建理論庫、Mental Strength Engine、教師實驗與成長儀表板都是單機運作，不需要任何 API Key。
